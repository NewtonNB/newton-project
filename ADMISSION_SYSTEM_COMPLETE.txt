========================================
DATABASE STRUCTURE
========================================

Table: student_applications

Columns:
- id (INT, PRIMARY KEY, AUTO_INCREMENT)
- name (VARCHAR 100, NOT NULL)
- date_of_birth (DATE, NOT NULL)
- gender (VARCHAR 10, NOT NULL)
- address (VARCHAR 200)
- nationality (VARCHAR 50)
- religion (VARCHAR 50)
- previous_school (VARCHAR 100)
- class_applying (VARCHAR 10)
- parent_name (VARCHAR 100, NOT NULL)
- parent_phone (VARCHAR 20, NOT NULL)
- email (VARCHAR 100)
- phone (VARCHAR 20)
- message (TEXT)
- photo (VARCHAR 255) - Path to uploaded photo
- status (ENUM: 'pending', 'approved', 'rejected', DEFAULT 'pending')
- created_at (TIMESTAMP, DEFAULT CURRENT_TIMESTAMP)

========================================
VALIDATION RULES
========================================

1. Full Name: Minimum 2 characters
2. Date of Birth: Must result in age between 5-25 years
3. Gender: Must select one option
4. Parent/Guardian Phone: Must match Ugandan format (^(\+?256|0)?[7][0-9]{8}$)
5. Email: Must be valid email format (if provided)
6. Student Phone: Must match Ugandan format (if provided)
7. Passport Photo: 
   - Accepted formats: JPG, PNG
   - Maximum size: 2MB
8. Message: Maximum 500 characters

========================================
UGANDAN PHONE NUMBER FORMATS
========================================

Valid formats:
- +256700123456
- 256700123456
- 0700123456

Pattern: Starts with optional +256 or 0, followed by 7, then 8 more digits

========================================
HOW TO USE
========================================

FOR STUDENTS/PARENTS:
1. Visit the Academics page
2. Click "Apply Now" button
3. Fill in all required fields (marked with *)
4. Upload passport photo (optional)
5. Review information
6. Click "Submit Application"
7. Wait for success notification
8. School admin will review and contact you

FOR ADMINISTRATORS:
1. Applications are stored in database
2. Access backend to view submissions
3. Review uploaded photos in /frontend/admission_photos/
4. Update status (pending/approved/rejected)
5. Contact applicants via provided phone/email

========================================
TROUBLESHOOTING
========================================

Issue: "No form data received"
Solution: Ensure form is submitted via AJAX, not direct navigation to backend

Issue: File upload fails
Solution: Check directory permissions on /frontend/admission_photos/

Issue: Phone validation fails
Solution: Verify format matches Ugandan pattern (+256 or 0 followed by 7XXXXXXXX)

Issue: Custom validation not showing
Solution: Check browser console for JavaScript errors, ensure jQuery is loaded

Issue: Database errors
Solution: Verify table exists by running create_applications_table.php
