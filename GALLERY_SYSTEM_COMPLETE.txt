## HOW THE SYSTEM WORKS
================================================================================

### Admin Panel → Frontend Flow:

1. UPLOAD IMAGE IN ADMIN PANEL
   - Admin logs into: /frontend/manage_gallery.html
   - Uploads image with category "Teachers" or "Non-Teachers"
   - Image saved to: /frontend/nyabzgallery/
   - Metadata saved to: /frontend/gallery_captions.json

2. BACKEND API
   - /backend/get_gallery_images.php reads metadata
   - Returns all images with categories, captions, and paths
   - /backend/get_teachers_public.php returns teacher records from database

3. FRONTEND DISPLAY
   - Staff.html loads teachers from database
   - Fetches gallery images with category="teachers"
   - For teachers without database photos, assigns gallery images
   - Images displayed from: nyabzgallery/filename.jpg

## HOW TO USE
================================================================================

### To Add New Teacher Images:

1. Login to admin panel: /frontend/login.html
   - Username: admin
   - Password: admin123

2. Go to Gallery Management: /frontend/manage_gallery.html

3. Click "Upload New Image" button

4. Fill in the form:

   - Enter caption (teacher name)
   - Select category: "Teachers"
   - Click Upload

5. Image automatically appears on /frontend/staff.html
   - Teachers without database photos get gallery images assigned
   - Uses round-robin distribution

### To Add Non-Teaching Staff Images:

1. Same steps as above
2. Select category: "Non-Teachers" 
3. Images appear on /frontend/nonstaff.html

   - Should return JSON with teacher records

4. Check image files exist:

   - Should contain 100+ image files
